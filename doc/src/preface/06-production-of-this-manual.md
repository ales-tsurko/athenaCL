# Production of This Manual

The first edition of the *athenaCL Tutorial Manual* was released in August of
2001 and covered athenaCL versions 1.0 to 1.3. The second edition was released
in June 2005 and covers athenaCL versions 1.4 and beyond. The third edition was
released in July 2010 and covers athenaCL versions 2.0.

The manual was originally written in DocBook and is now kept as Markdown, in the
`doc` directory of the athenaCL sources. It is published with
[mdBook](https://rust-lang.github.io/mdBook/), and the same pages are built into
athenaCL itself, where the `AUdoc` command reads them.
